# Project: archiefwaardige opslag

Dit deel van de site bevat de projectnotities van de opdracht "Nextcloud archiefwaardige opslag, iteratie 1". Conduction voert de opdracht uit voor het programma Common Ground van VNG. Open WebConcept is Product Owner. Erik Hoekstra (gemeente Haarlem) beoordeelt en accepteert de resultaten.

Vanaf 16 november 2026 staan alle projectnotities in deze repository. Wie een notitie wil aanvullen of corrigeren, doet een pull request op de branch `development`.

## Doel

Nextcloud geschikt maken voor archiefwaardige opslag: een verwijdering die de opslaglaag weigert, metagegevens uit de opslaglaag die niemand in Nextcloud kan wijzigen, en een duurzame identiteit per record. De voorstellen bouwen voort op de technische notitie *Records-management backend support in Nextcloud* van Erik Hoekstra (gemeente Haarlem), 19 augustus 2026.
